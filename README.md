# 🍕 Pizza Sales Analysis Dashboard (Power BI)

## 📌 Project Overview
This project focuses on analyzing pizza sales data using **SQL** and **Power BI** to generate meaningful business insights.  
The dashboard provides a complete sales overview including revenue trends, customer ordering behavior, best-selling pizzas, and peak order times.

The analysis helps stakeholders understand:
- Sales performance
- Customer preferences
- Peak business days and months
- Product contribution to revenue

---

## 🛠️ Tools & Technologies
- **Power BI** – Data visualization & dashboard creation  
- **SQL** – Data analysis & KPI calculations  
- **Microsoft Word** – Project report documentation  
- **Dataset** – Pizza sales transactional data  

---

## 📊 Key KPIs
- **Total Revenue:** $817.86K  
- **Average Order Value:** $38.31  
- **Total Orders:** 21K  
- **Total Pizzas Sold:** 50K  
- **Average Pizzas per Order:** 2.32  

---

## 📈 Dashboard Features
- Total Revenue, Orders, and Sales KPIs
- Top Selling Pizza Categories
- Orders by Day of Week
- Monthly Order Trends
- Revenue Distribution by Pizza Category
- Revenue Distribution by Pizza Size
- Business insights on peak days and months

---

## 🧠 Key Insights
- Highest orders occur on **Friday and Saturday evenings**
- **July and March** record the maximum monthly orders
- **Classic pizzas** contribute the highest revenue
- **Large-sized pizzas** generate the most revenue
